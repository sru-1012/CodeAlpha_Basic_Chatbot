# CodeAlpha_Basic_Chatbot
🤖 Rule-Based Chatbot
A simple rule-based chatbot built in Python that responds to user inputs using predefined replies. No external libraries required.

📋 Features

Responds to common inputs like greetings, questions, and farewells
Shows the current time when asked
Typing effect for natural-feeling replies
Runs in a continuous loop until the user exits


🗂️ Project Structure
chatbot/
│
└── chatbot.py       # Main chatbot script

🚀 Getting Started
Prerequisites

Python 3.x

Installation

bashgit clone https://github.com/your-username/chatbot.git
